# HostelConnect

## Multi-University Student Hostel Booking System in Ghana

### 1. Project Overview

HostelConnect is a web-based system designed to
help tertiary students discover and book private
hostel accommodation around their universities.

The system connects students with hostel owners
through a centralised accommodation platform.

### 2. Problem Being Solved

Students often experience difficulties finding
suitable hostel accommodation, comparing prices
and checking room availability.

The system seeks to simplify this process through
online hostel discovery and room reservations.

### 3. Project Objectives

- Develop a user registration and authentication system.
- Enable students to search and view hostels.
- Allow students to check room availability.
- Implement an online room booking system.
- Integrate an external payment service.

### 4. Initial Project Coverage

The initial demonstration will cover:

- USTED
- KNUST
- Kumasi Technical University (KTU)

The system will support additional universities
through its database design.

### 5. Core Features

1. User Management
2. Hostel Discovery
3. Room Booking
4. Payment and Booking Confirmation

### 6. User Categories

- Students
- Hostel Owners
- System Administrators
